# Gracious Givers Trust Website

A responsive static website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new public GitHub repository, for example `gracious-givers-trust`.
2. Upload `index.html`, `styles.css`, `script.js`, and the complete `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. GitHub will provide a `https://YOUR-USERNAME.github.io/gracious-givers-trust/` address.

## Connect your own domain
1. In **Settings → Pages → Custom domain**, enter your domain (for example `www.example.org`) and Save.
2. At your domain registrar, add a CNAME record:
   - Host/Name: `www`
   - Target/Value: `YOUR-USERNAME.github.io`
3. If you also want the apex/root domain (example.org), configure the four GitHub Pages A records shown in GitHub's current documentation.
4. Wait for DNS to propagate, then enable **Enforce HTTPS** in GitHub Pages.
